URBAN LEAVES UAE WEBSITE — LOGO UPDATE

This package contains:
- index.html
- urban-leaves-emblem.png (round logo used in the navigation and as the browser icon)
- urban-leaves-header.png (horizontal logo used near the top of the homepage)

How to update your existing GitHub Pages repository:
1. Extract this ZIP on your computer.
2. Open https://github.com/muhammadyousuf91/smart-home-finds-uae
3. Select Add file > Upload files.
4. Upload both PNG images to the repository root.
5. Replace the existing index.html with this package's index.html. If uploading it through the upload screen does not replace it, open the existing index.html, click Edit, select all, and paste the contents of this package's index.html.
6. Commit changes to the main branch.
7. Wait for the GitHub Pages deployment to finish, then refresh the site with Ctrl+F5.

Important: all three files must sit in the repository root (same level as README.md), not in a nested folder, because the HTML refers to the logo images by their root filenames.

This package is prepared locally and is not automatically deployed to GitHub.
